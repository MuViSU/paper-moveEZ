# moveEZ: An R Package for Animated Biplots

This repository contains the required files to reproduce the paper titled: "moveEZ: An R Package for Animated Biplots"

## Description

-   [`figures`](figures): Contains the figures used in this paper.
-   The manuscript is written using [Rmarkdown](https://rmarkdown.rstudio.com/). The TeX and PDF files for the paper are generated by rendering the [`moveEZ.rmd`](movEZ.rmd) file.
